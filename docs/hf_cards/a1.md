# Tiny Aya Global xref-v2 + RepNoise (A1, research checkpoint)

A1 is [xref-v2](https://huggingface.co/StarWarrior24x7/tiny-aya-global-xref-v2) trained further with **RepNoise**, a published defense against harmful fine-tuning. It is part of Phase A of the [Heretic-Resistant Tiny Aya project](https://github.com/ShivenduShivu/Tamper_Resistance_OSModels/blob/main/README.md) and is published as a **research checkpoint, not a recommended model**.

**Finding:** A1 holds off a harmful LoRA fine-tune 3.5–4× longer than v2 (held-out HarmBench prompts, two attack seeds, predictions written before the runs). It still breaks in the end: this is **delay, not prevention**.

## Capability cost (clean checkpoint, change vs v2)

Same frozen items, settings and scorers as the project's capability audit. Paired Newcombe 95% intervals; exploratory, one training seed. Source: [`results/phaseA_capability/`](https://github.com/ShivenduShivu/Tamper_Resistance_OSModels/blob/main/results/phaseA_capability/README.md).

| Benchmark | v2 | A1 | A1 − v2 [95% CI] |
|---|---:|---:|---:|
| HumanEval pass@1 | 70/164 (42.7%) | 37/164 (22.6%) | **−20.1 [−27.4, −12.5]** |
| GSM8K, numeric parser | 141/200 (70.5%) | 118/200 (59.0%) | **−11.5 [−18.0, −4.9]** |
| GSM8K, strict | 113/200 (56.5%) | 104/200 (52.0%) | −4.5 [−11.4, +2.5] |
| IFEval, prompt strict | 135/200 (67.5%) | 125/200 (62.5%) | −5.0 [−11.6, +1.7] |
| MMLU | 109/200 (54.5%) | 110/200 (55.0%) | +0.5 [−3.6, +4.6] |
| CyberMetric | 384/500 (76.8%) | 363/500 (72.6%) | **−4.2 [−6.8, −1.7]** |
| XSTest safe prompts flagged as refused | 107/250 (42.8%) | 85/250 (34.0%) | −8.8 [−13.4, −4.1] |

**Trade-off:** A1 keeps roughly half of v2's HumanEval passes (37 vs 70 of 164) and loses maths and security knowledge, but refuses fewer safe questions than v2.

## Use

```python
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer

repo = "StarWarrior24x7/tiny-aya-global-phaseA-v2-repnoise"
tok = AutoTokenizer.from_pretrained(repo)
model = AutoModelForCausalLM.from_pretrained(repo, dtype=torch.float16, device_map="auto")

msgs = [{"role": "user", "content": "Write a Python function that reverses a string."}]
text = tok.apply_chat_template(msgs, tokenize=False, add_generation_prompt=True)
enc = tok(text, add_special_tokens=False, return_tensors="pt").to(model.device)  # the template already adds BOS
out = model.generate(**enc, max_new_tokens=256, do_sample=False, eos_token_id=[tok.eos_token_id, 3])
print(tok.decode(out[0, enc["input_ids"].shape[1]:], skip_special_tokens=True))
```

## Limitations
- **Delay, not prevention:** harmful fine-tuning still removes refusal; A1 only takes longer to break.
- Clean-checkpoint capability only; capability after tampering is unmeasured.
- Refusal labels are provisional ProtectAI classifier output under a 128-token cap, not human-validated.
- One model size (3.35B), one training seed.
